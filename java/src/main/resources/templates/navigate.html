VCF/400 - How to Navigate

Before you start, here is how to navigate:

  1. Use ARROW KEYS or TAB KEY to move between fields.
  2. Use F5 or ENTER to perform your action.
  3. Use F12 to quit at any time.
  4. Keyboard not responding? If you see X II in the left corner, press RIGHT CTRL to continue.

On this modern UI the same keys work on a physical keyboard, and every action button also shows its key.
